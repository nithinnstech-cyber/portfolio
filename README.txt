# Nithin N S - HTML & CSS Portfolio

This portfolio is built using only:

- HTML5
- CSS3

No JavaScript, Bootstrap, React, Tailwind or other frameworks are used.

## How to run

1. Extract the ZIP file.
2. Open the `nithin-portfolio` folder in VS Code.
3. Open `index.html` in your browser.

For a better development experience, you can use the VS Code Live Server extension.

## Folder structure

nithin-portfolio/
│
├── index.html
├── README.txt
├── css/
│   └── style.css
└── images/

The images folder is intentionally empty. If you want a profile photo later,
put your image inside `images/` and replace the initials card in `index.html`.
